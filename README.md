# Physics-Informed Machine Learning Screening of MOF/g-C3N4 Heterojunctions

Implementation of the paper: **"Physics-Informed Machine Learning Screening and Validation of Metal-Organic Framework/g-C3N4 Heterojunctions Photocatalysts."**

This repository contains my source code for feature engineering, ensemble modeling, and SHAP analysis used to identify stable candidates from the QMOF database.
